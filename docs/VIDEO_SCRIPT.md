# Demo Video Script — 3 minutes

- 0:00–0:20 Problem and tagline: "Draw it, say it, ship it."
- 0:20–0:50 Draw a sketch on the canvas and add a voice note.
- 0:50–1:30 Show the generated spec and edit one item.

- 2:30–3:00 Kiro usage (Specs, Steering, Hooks, MCP) and what's next.

Video must be YouTube only, public or unlisted, no password, and everything needed to evaluate the project must be within the first 3 minutes.

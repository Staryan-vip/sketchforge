# Product Steering

## Product
SketchForge turns a hand-drawn sketch and a voice note into a working full-stack prototype.

## Users
Indie developers, product managers, creators, and students who have an idea but no runnable prototype yet.

## Core promise
From idea to runnable app in minutes, with a human-readable spec in the middle that the user can correct before code is generated.

## Non-goals
- Not a static mockup tool. Output must be runnable, not just a picture of an app.
- Not a prompt-only code generator. Sketch and voice are first-class inputs, alongside text.
- No hidden motive in outward filings: present as a genuine participant building a product.
